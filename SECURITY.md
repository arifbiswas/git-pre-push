# Security Policy

## Supported Versions

We actively provide security updates and rule definitions for the latest release:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability or New Malware Signature

Security is our primary mission. If you discover a security vulnerability in `git-pre-push`, or if you identify a new infostealer signature / bypass technique that should be added to our detection rules:

1. **Please do NOT open a public issue.**
2. Send an email to the maintainer or use [GitHub Private Vulnerability Reporting](https://github.com/arifbiswas/git-pre-push/security/advisories/new).
3. Provide details including:
   - Operating system and Node.js version
   - Sample commit payload or infected file structure (sanitized)
   - Steps to reproduce the bypass or vulnerability

We will review, acknowledge, and issue a patched release promptly.
